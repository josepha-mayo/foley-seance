Privacy, export details & verification

No microphone access or upload is required. Source and edits live only in this tab unless you explicitly save a project file. Save a project or download your WAV before closing. Changing a control invalidates the previous cue until you summon again.

We create a 16-bit PCM WAV once, decode those exact bytes, and use the decoded samples for preview. All in-app listening uses the same 0.35 monitor gain, not loudness normalization. Different sounds and effects can still sound louder or quieter. This gain and short playback edge fades do not alter the downloaded WAV. Your browser and speakers can still resample or color playback. The downloaded file includes a bounded 1.50-second tail, faded over its last 50 ms; this is not a renamed compressed recording.
